# Loan Default Prediction System

## 📌 Project Overview
This project predicts whether a loan applicant is likely to default using machine learning. The goal is to help financial institutions identify high-risk applicants and support better lending decisions.

---

## 🎯 Objectives
- Analyze loan applicant data
- Perform data preprocessing
- Train and evaluate machine learning models
- Visualize insights using Power BI
- Predict loan default risk

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
- Power BI
